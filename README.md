# MiPrimerTelescopio.com

Guía independiente en español para elegir o regalar el primer telescopio astronómico (Celestron, Sky-Watcher, Gskyer y Orion) y accesorios compatibles en Amazon Estados Unidos (`miprimertelescopio-20` US / `miprimertelescopio03-21` ES).

- **Stack**: Next.js 16 App Router (100 % SSG estático), Tailwind CSS v4, GSAP, Lenis.
- **Contenido**: 14 hubs pilares + 520 artículos transaccionales + 1,000 artículos SEO informacionales sin canibalización (1,534 guías + 7 páginas legales + Home).
- **Backend & Chat IA**: Supabase (`charlielingan` · `ehwjvuhbimqakvzqbvvg`) con Edge Functions `miprimertelescopio-chat` (`gpt-4o-mini` predeterminado) y `miprimertelescopio-images` (`gpt-image-1` calidad media, WebP `< 100 KB`).
